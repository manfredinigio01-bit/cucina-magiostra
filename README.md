# Cucina La Magiostra

App per ricettario, food cost e prezzi d'acquisto della cucina di La Magiostra (Cremona).
Indirizzo: https://manfredinigio01-bit.github.io/cucina-magiostra/

Questo repository contiene **solo il programma**. I dati stanno nel repository privato `magiostra-cucina-dati` e si aprono solo con password e chiave.
